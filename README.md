# Fudosan

A simple PHP real-estate landing page project for a property marketplace.

## Features
- Responsive landing page
- Property cards with featured listings
- Simple PHP structure
- Easy to extend for admin or database features

## Run locally

```bash
php -S localhost:8000 -t .
```

Then open:

```text
http://localhost:8000/
```

## Project structure

```text
/
├── assets/
│   └── style.css
├── data/
│   └── properties.php
├── includes/
│   └── config.php
├── index.php
├── .gitignore
└── README.md
```

## Notes
This is a starter project and can be expanded into a full PHP + MySQL property management system.
